# Mukhtalif Ventures — Logistics Website 🚚

A multi-page logistics website built as a frontend implementation project, with a structured information architecture, reusable components, responsive layouts, and a defined brand system.

> **Portfolio note:** Confirm that you have permission to publish this project and its branding/content before using it in public job applications.

## ✨ Highlights

- Multi-page logistics experience covering services, industries, coverage, tracking, careers, blog, contact, and quote requests
- Dynamic service detail pages
- Reusable navigation, cards, counters, and route-line visual components
- Responsive layouts
- Centralized content/data structure
- Brand-driven typography, color, spacing, and interaction patterns
- UI-complete forms and demo tracking flow

## 🛠️ Tech stack

- **Framework:** Next.js 14, App Router
- **Language:** TypeScript
- **UI:** React + Tailwind CSS
- **Typography:** Manrope, Inter, IBM Plex Mono

## 🚀 Run locally

```bash
cd mv-logistics
npm install
npm run dev
```

Open `http://localhost:3000`.

## 📌 Current limitations

The current build uses placeholder hero imagery, UI-only forms, and a mock Track & Trace result. These are intentionally documented rather than presented as production integrations.
